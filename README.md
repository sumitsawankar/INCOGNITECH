# IncogniTech – Smart Learning Platform for Engineering Students

IncogniTech is a modern educational platform built to simplify academic learning for engineering students by bringing together study materials, notes, previous year question papers, practical resources, and collaborative learning tools in one centralized platform.

The project aims to eliminate the hassle of searching across multiple websites, WhatsApp groups, and cloud drives by providing a structured, user-friendly, and accessible repository of academic resources.

Designed with students in mind, IncogniTech combines clean UI/UX, responsive design, and an intuitive navigation experience to help learners focus on what matters most—learning.

# Project Vision

Engineering students often spend hours searching for reliable notes, assignments, lab manuals, question papers, and study resources scattered across different platforms.

IncogniTech was created to solve this problem by becoming a **single academic hub** where students can quickly access verified educational content, share knowledge, and prepare effectively for examinations.

Our vision is to build a student-first ecosystem that makes learning more accessible, collaborative, and efficient.

---

# Problem Statement

Students frequently face challenges such as:

- Study materials scattered across multiple platforms.
- Difficulty finding semester-wise notes.
- Lack of organized previous year question papers.
- No centralized platform for academic collaboration.
- Time wasted searching for reliable resources.
- Limited access to quality educational content.

IncogniTech addresses these problems by providing a structured digital platform that organizes academic resources in one place.

---

IncogniTech provides a centralized platform where students can:

- Access semester-wise notes
- Download previous year question papers
- Find practical and laboratory resources
- Explore subject-wise study material

# Installation

Clone the repository

```bash
git clone https://github.com/yourusername/incognitech.git
```

Navigate to the project directory

```bash
cd incognitech
```

Install dependencies (if applicable)

```bash
npm install
```

Run the development server

```bash
npm run dev
```

For static deployment, simply open `index.html` in your browser or use VS Code Live Server.
